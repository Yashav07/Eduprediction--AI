# EduPredict AI

AI-Based Student Performance Analysis and Prediction System.

## Files
- `app.py`: Streamlit application.
- `requirements.txt`: Python dependencies.

## Deploy
Deploy this GitHub repository with Streamlit Community Cloud.
Set the main file path to `app.py`.

## Important note
The Random Forest model in this starter project is trained on synthetic
demonstration data. Its predictions are for demonstrating the workflow only.
For meaningful real-world predictions, replace the synthetic data with
appropriate anonymized historical academic records and validate the model.
